# Quiet Blue · 审核台皮肤

独立工作区：`review-claude-skin/审核台`。分支：`codex/review-claude-skin`。

此方案采用温润深蓝与低对比表面层级。保留 TOTAL / PROJECT / REVIEW 的审核产品结构；扫描结束进入修订，仍使用共享审核引擎与真实规则计数。

## 设计决策

- **TOTAL**：左对齐标题；四项总览直接显示数值；活动保持正方形；过往项目和规划沿同一内容轴排列，不把每段再包一张卡。
- **PROJECT**：成员位于标题下方，保留可折叠；姓名、区域、语种使用系统字体，料号用等宽字体。BOM / SKU 和添加入口均保留。
- **REVIEW**：项目、单一状态、三项扫描数据为第一层；代码流与四个 5×5 阵列为第二层；真实规则进度与扫描操作为第三层。高度、字体尺度和宽短窗口两栏布局沿用共享响应式规则，皮肤仅修改材质、色彩和字体族。
- **修订**：结果及一键修订为主要操作；模型设置继续折叠。输入框、选择框、结果记录和弹窗沿用相同表面、圆角和蓝色焦点。
- **弹窗**：背景模糊、略高明度表面、一道边框。主按钮明暗对比清晰，关闭按钮为低强调的方形点击区。
- **动效**：皮肤只负责控件、页面、弹窗与遮罩。扫描入场、旧行推进、粒子化与真实事件队列由共享实现负责，不通过 CSS 无限循环伪造工作状态。
