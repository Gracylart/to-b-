# Apple 皮肤 · Review Desk

独立分支：`codex/review-apple-skin`。通过 `dist/index.html` 的 `data-skin="apple"` 与 `skins/apple.css` 加载，产品逻辑、扫描事件和桌面能力来自共享实现。

## 视觉方案

默认交付浅色：冰蓝外壳、接近白色的内容表面、清楚的深色正文、单一蓝色操作重点。适合持续工作的 macOS 菜单栏面板。

- 系统字体优先 `-apple-system`，使用系统自带 SF 与苹方；未下载或分发 Apple 字体文件。常规内容与说明使用系统无衬线，只有代码、料号和部分数字保留等宽。
- 标题紧密字距；正文常规字距；基本字号随窗口宽度由 13 到 15 px 伸缩，辅助信息最低约 12 px。缩窗通过滚动解决，不缩小文字隐藏内容。
- 导航是系统分段控件。主操作是饱和蓝色按钮，次操作是白色控件。浮层有明显上缘高光、细边与分层阴影。主要玻璃效果放在外壳和弹窗，输入框使用稳定的近白底。
- 首页统计改为“数字优先、说明随后”，避免四组指标权重一致。桌面宽度达到 680 px 时，活动与过往项目并列；项目规划占据完整一行。活动方格保持正方形。
- 项目成员是基础信息组，保留可折叠行为；BOM 与 SKU 保持折叠。复制料号无占据注意力的提示。
- REVIEW 使用共享精简结构：一次项目选择、一次状态、紧凑统计、真实扫描流与四组规范阵列。皮肤不改扫描速度、进度或阵列几何，不添加虚假日志或装饰性运行标记。
- 修订页面沿用同一套输入、明细和操作层级。模型设置可收起，主修订操作突出；不把配置界面当作主任务。
- 动效只补充轻微按下反馈，不叠加持续闪烁。文字流的逐行出现、推进与顶部退场由共享工作流引擎负责。

## 可访问性与适配

- 键盘焦点有 2 px 蓝色轮廓与间距。
- 遵循 `prefers-reduced-motion`、`prefers-reduced-transparency`、`prefers-contrast`，并保留原有“减少动态效果”工作流设置。无 `backdrop-filter` 时使用实体底色。
- 桌面鼠标操作采用紧凑 macOS 尺寸；粗指针设备的主要操作与列表入口至少 44 px。未为达到触屏尺寸而挤压窄桌面中的阅读空间。
- 深色语义 token 可用 `data-theme="dark"` 验证，默认 `light` 保持本方案的冰蓝白色视觉。
- 340 × 520 到 960 px 宽的完整内容由现有滚动容器承载，底部按钮不做不可达的固定裁切。
