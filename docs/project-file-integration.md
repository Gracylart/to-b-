# 项目文件侧栏 · Studio 1.2.1

在现有审核台桌面应用中集成，沿用侧栏方案的图标、颜色和表面。桌面产品只有侧栏形态；可编辑参考原型和原有数据保留。

## 使用

- 平时在屏幕边缘显示窄把手，鼠标停留后展开图标栏；离开图标栏和文件面板后延迟收起。悬停展开不会抢焦点。
- 每个项目图标就是一个项目文件夹入口，点击后在侧栏里查看具体文件。首页图标打开项目列表，顶部按钮展开或收起侧栏内容。
- 支持竖向和横向图标栏，右键顶部按钮可切换。菜单栏可选择左右停靠和关闭自动收起。
- 不提供普通窗口、最小化、最大化、全屏或“打开完整工作区”入口。展开面板的关闭按钮收起面板；系统关闭请求返回边缘把手。
- 文件面板包含物料、阶段表格、借用和待确认。变更稿按同物料聚合，借用料保留原项目号及引用关系。
- 文件名按钮用系统默认应用打开原文件，文件夹按钮在 Finder 中定位。输入搜索或选择项目期间保持展开。
- 底部设置图标直接打开文件来源。桌面和下载默认开启，项目总目录选择一次后持续监听，每个来源可单独暂停。项目列表中另有“待确认文件”入口，用于给缺少项目号的文件人工确认归属。
- “集中”指项目内的虚拟聚合展示，原文件保留在原位置，不复制、移动或改名。

## 本地数据与模型

索引位于 `~/Library/Application Support/文案审核台 · Studio/project-files.json`。文件索引只保存元数据与归属，不移动、改名或复制原文件。支持 PDF、XLSX、XLS、XLSM、CSV、TSV、文本、AI、SVG 和常见图片的文件名归集；可提取文字的 PDF、Excel 和文本可供内容判断。扫描 PDF 和图片未接 OCR，仅凭文件名无法识别时保留待确认。

首次扫描后使用独立进程中的原生 FSEvents 目录监听和定时增量核对。系统文件提供器可能阻塞原生目录监听，监听进程可单独结束，不阻塞主界面或应用退出；不会递归监听应用包、隐藏目录或符号链接。单文件事件直接更新索引；文件元数据查询也在独立进程中执行，超时后重启该进程，防止无法取消的系统调用耗尽文件线程；后台全量扫描设置时间上限，分批刷新，通过事件和定时核对处理新增、改名、删除与来源暂不可用。内容提取在受限时长的独立进程中串行执行，退出应用会终止提取进程，Excel 不执行公式或宏。手动确认优先于晚到的模型结果；未在原文验证的项目、阶段与物料不会直接采纳。

未匹配的模型结果按文件版本缓存。只有示例项目、没有实际项目文件时，不对个人桌面资料反复运行分类；选择真实项目目录后再处理关联内容。移除目录中的文件后，会清除没有文件引用的自动发现项目。

模型使用 Qwen 官方 Qwen3-0.6B Q8_0，权重约 639 MB，模型名称 `qwen3:0.6b`。Ollama 运行时位于用户数据目录 `runtime/`，权重位于 `models/`；不随应用重复打包。应用通过 `127.0.0.1:11437` 使用本地模型，关闭云功能，隐藏窗口后仍可归集，退出应用会结束其启动的模型服务。原文不发送远程模型。小模型的语义判断仍可能不准确，项目关联必须有原文或路径证据，不使用模型自报的置信度作为自动归集依据。

## 目录权限

macOS 文件服务使用 utilityProcess，并显式保持父应用的 TCC 权限归属（disclaim=false），避免助手各自申请目录权限。首次访问桌面、下载仍由系统请求授权。拒绝访问后暂停对应来源，后台不重复重试；通过“重新选择”按钮恢复。首次目录读取为权限对话框留出时间，避免将等待授权误判为两秒超时并反复重启。

本机没有正式代码签名身份（security find-identity 返回 0）。当前安装包使用临时签名，其 designated requirement 绑定本次代码版本，因此重新打包更新后系统仍可能再次请求授权。跨版本稳定保留授权需要稳定的签名身份；本应用不要求全盘访问，也不更改系统隐私保护。

参考：[Electron utilityProcess](https://www.electronjs.org/docs/latest/api/utility-process)、[Apple TN3127](https://developer.apple.com/documentation/technotes/tn3127-inside-code-signing-requirements)。

## 验证

`npm test`（76 项）、`npm run check`、`npm run build:mac:dir`。另外执行 `npm run test:desktop-services -- --with-model`，在真实 Electron Utility 进程中验证 PDF、Excel、文件事件与本地 Qwen 关联。覆盖侧栏导航、禁止普通窗口形态、无最小化和全屏入口、AppKit 延迟恢复、项目号规范化、IPC 来源、监听、模型证据校验、真实 PDF 和 Excel 提取、目录拒绝后的暂停及元数据进程卡住后的恢复。

原生文件服务实测约 0.5 秒发现新增验收文件。内容型 PDF 通过正文项目号完成本地模型关联。验收仅使用独立测试文件，完成后移出桌面。Numbers 首次启动有系统许可协议，未代用户接受。

本机还保留 Apple、Quiet Blue 和旧版审核台；本次更新入口是 `/Applications/文案审核台 · Studio.app`，版本 1.2.1。

内容识别结果会应用到目录刷新后的当前文件记录；新到文件优先于历史积压。Electron 文件服务测试覆盖识别期间再次扫描的场景。

最终安装包在桌面、下载通过目录选择器确认访问后，同版本重启读取测试 PDF，约 1 秒完成正文项目号关联，无需再次选择目录。已验证项目侧栏同时显示桌面 PDF、下载文件、借用来源与变更稿集合。测试文件已全部移出监听目录。
