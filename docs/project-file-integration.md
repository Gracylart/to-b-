# 项目文件归集 · Studio 1.2.0

在侧栏工作区方案现有 Electron 应用中接入，沿用已完成的双栏参考 UI、系统字体和图标。原始 `replica.html` 与可编辑原型保留。审核、PDF 批注和修订流程继续使用原有实现。

## 使用

- 顶部侧栏按钮切换完整工作区与 64 px 文件侧栏；右键该按钮切换竖向、横向停靠。菜单栏右键菜单也提供三个形态。
- 竖栏默认停靠右侧，平时只显示 10 × 88 px 的边缘把手；鼠标停留约 80 ms 后展开，离开侧栏及文件弹层约 320 ms 后收起。悬停展开不抢焦点，点击才激活。横栏在底部保留把手。菜单栏可切换左右停靠、关闭自动收起。输入搜索、选择项目或原生文件夹选择框期间保持展开。
- 收起时点击或悬停有实际文件的项目图标，临时展开文件集。点击文件名由系统默认应用打开；旁边的文件夹按钮在 Finder 中定位。
- 同物料的变更稿聚合为版本集合。表格按文件名中的独立阶段后缀识别；借用料保留原项目编号，共享原文件，可建立对当前项目的引用。
- 纯图标栏底部的设置图标可直接打开文件来源，无需展开完整工作区。文件来源设置默认开启桌面和下载，项目总目录通过系统文件夹选择器添加。每个来源可单独暂停监听。

## 本地数据与模型

索引位于 `~/Library/Application Support/文案审核台 · Studio/project-files.json`。文件索引只保存元数据与归属，不移动、改名或复制原文件。支持 PDF、XLSX、XLS、XLSM、CSV、TSV、文本、AI、SVG 和常见图片的文件名归集；可提取文字的 PDF、Excel 和文本可供内容判断。扫描 PDF 和图片未接 OCR，仅凭文件名无法识别时保留待确认。

首次扫描后使用独立进程中的原生 FSEvents 目录监听和定时增量核对。系统文件提供器可能阻塞原生目录监听，监听进程可单独结束，不阻塞主界面或应用退出；不会递归监听应用包、隐藏目录或符号链接。单文件事件直接更新索引；文件元数据查询也在独立进程中执行，超时后重启该进程，防止无法取消的系统调用耗尽文件线程；后台全量扫描设置时间上限，分批刷新，通过事件和定时核对处理新增、改名、删除与来源暂不可用。内容提取在受限时长的独立进程中串行执行，退出应用会终止提取进程，Excel 不执行公式或宏。手动确认优先于晚到的模型结果；未在原文验证的项目、阶段与物料不会直接采纳。

未匹配的模型结果按文件版本缓存。只有示例项目、没有实际项目文件时，不对个人桌面资料反复运行分类；选择真实项目目录后再处理关联内容。移除目录中的文件后，会清除没有文件引用的自动发现项目。

模型使用 Qwen 官方 Qwen3-0.6B Q8_0，权重约 639 MB，模型名称 `qwen3:0.6b`。Ollama 运行时位于用户数据目录 `runtime/`，权重位于 `models/`；不随应用重复打包。应用通过 `127.0.0.1:11437` 使用本地模型，关闭云功能，隐藏窗口后仍可归集，退出应用会结束其启动的模型服务。原文不发送远程模型。小模型的语义判断仍可能不准确，项目关联必须有原文或路径证据，不使用模型自报的置信度作为自动归集依据。

## 验证

`npm test`（67 项）、`npm run check`、`npm run build:mac:dir`。回归覆盖实际 PDF/Excel 内容提取、目录监听、改名、删除、临时文件和符号链接、人工确认与模型并发、虚构阶段拒绝、IPC 来源和原有审核流程。

在真实 macOS 构建产物中检查完整工作区、纯侧栏、横向图标条、项目文件弹层、PDF 在预览中打开、Excel 交给 Numbers、文件夹选择器和借用来源。Numbers 首次启动显示许可协议，未自动接受；Excel 内容解析由本地测试验证。桌面验收使用单独的 `QA2710` / `QA2609` 测试文件，完成后清理，不计入审核历史。

最终安装包实测：桌面和下载新增文件约 0.5 秒进入索引；不含项目号的 PDF 文件名通过正文中的项目号在约 2 秒内由本地模型关联。验收文件已移出桌面与下载，索引随删除事件更新。冷启动恢复竖栏、横栏和正常退出已验证。
