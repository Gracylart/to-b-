# 1.0.11 视觉与交互验收

日期：2026-10-24。范围：共享审核流程，以及 Apple / Quiet Blue 两个独立皮肤工作区。

## 交互取舍

- 删除重复项目面包屑、重复运行状态、`review.worker.ts` / `rule-engine` 技术标签与闪烁光标。
- 项目选择和运行状态合并；已检查、通过规则、待修订保留为紧凑摘要。
- 初始代码区域为空；扫描事件发生后才显示 `check("rule-id")` 与本次结果，完整文件名只在标题及行的提示中出现。
- 历史行保留 DOM；新增行轻微位移、透明度和模糊归零，列表使用连续临界阻尼位移。220 ms 合批只影响呈现，规则计数仍来自实际执行结果。
- 真实越过顶部裁切线的文字才粒子化；暂停冻结同一时间轴，恢复不补跳墙钟时间。减少动态效果模式直接更新结果。
- 窄短窗口减少间距；宽短窗口用横向布局容纳代码、阵列和分类进度。代码字号上限 15 px。
- 移除物料行暗示详情页的箭头；BOM / SKU 显示当前展开状态，保留一键静默复制。
