# 审核台侧栏方案 · Studio

Studio 是与原版、Apple、Quiet Blue 完全隔离的桌面发行版。它使用独立名称、Bundle ID、单实例锁与 `userData` 路径，不覆盖其他版本。

## 信息架构

- 64 px 图标栏：总览、项目、审核/修订、主题与设置。
- 248 px 二级导航：工作区入口、真实项目树、文案导入与审核规范，可收起为图标栏。
- 主工作区：1200 × 800 默认窗口，640 × 520 最小窗口；采用 macOS `hiddenInset` 原生顶栏与交通灯。

总览只把真实审核历史计入耗时、通过率、文档数和项目数；没有记录时显示 `— / 0`，不以示例伪造指标。项目页保留成员角色、区域/语种、BOM/SKU 折叠、BOM 新增以及纯数字料号静默复制。审核项目只在审核页选择，完成后自动进入批注与修订。

## 设计规范

界面采用 open-claude-ui（MIT）的语义化 Surface 0–3、发丝线、单闭合边框、系统字体栈、规范控件尺寸、焦点环、物理缓动、减少动态效果、中文输入法守卫与七段非线性滚动遮罩。品牌强调色按产品要求改为蓝色；浅色主题使用苹果式冰蓝与中性白。

审核动效保留四组等大 5 × 5 阵列、每类别真实执行计数、按文件和规范变化的独立节奏、逐行真实扫描事件、连续阻尼位移、顶部越界后粒子化，以及暂停冻结。Canvas 粒子颜色从主题变量读取，浅色主题不使用固定白色核心。

## 桌面视觉验收

2026-10-24 在真实 Electron/macOS 窗口中检查：

- 深色和浅色的总览、项目、审核、修订与设置弹窗；
- 展开与收起二级导航；
- 审核空态、运行、暂停、完成后自动进入修订；
- 无 API Key 时阻止 DeepSeek 修订并显示明确错误；
- 1200 × 800 宽窗和约 750 × 525 短窗；
- 原生交通灯、窗口缩放与菜单栏入口。

验证命令：`npm test`、`npm run check`、`npm run build:mac:dir`。
